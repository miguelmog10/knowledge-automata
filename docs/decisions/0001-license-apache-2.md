# 0001. License: Apache 2.0

- **Status:** Accepted
- **Date:** 2026-10-24

## Context

This is the owner's first open-source project and a public portfolio piece. The licence must allow broad reuse while protecting the owner and contributors.

## Decision

License the project under Apache 2.0.

## Consequences

- Permissive and commercial-friendly.
- Compared with MIT, adds an explicit patent grant and a patent retaliation clause.
- Requires attribution.
- Does not grant trademark rights, so the project name stays with the owner.
- Future proprietary work can be built on top as separate code.
