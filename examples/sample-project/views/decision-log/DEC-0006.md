# DEC-0006: Offline count conflict handling

Back to the [decision log](../decision-log.md).

## Decision

The app will keep the most recent count and ask the grower to confirm which count is correct.

## Context

Conflicting offline counts caused the app to double batch counts when multiple growers counted the same bench.

## Rationale

To fix the failure where conflicting offline counts caused the app to double batch counts.

## Decided by

Marc Gagnon, Sofia Ramos

## Impacts

The app will display both counts and require grower confirmation, preventing double counting.
