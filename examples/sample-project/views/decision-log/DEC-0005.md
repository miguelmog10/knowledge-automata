# DEC-0005: Offline count conflict: add counts instead of overwrite

Back to the [decision log](../decision-log.md).

## Decision

When two offline counts of the same batch conflict, the app keeps both changes and adds them together, instead of keeping only the last count.

## Context

Two offline counts of the same batch conflict.

## Rationale

Sofia explained that growers often split one bench between two people, so both counts are usually real.

## Alternatives considered

- Keep only the last count (overwrite)
