# DEC-0003: Replace single status ladder with crop-specific paths

Back to the [decision log](../decision-log.md).

## Decision

The board replaced the single status ladder with one status path per crop type.

## Context

The existing status ladder did not fit growers' workflow, causing unnecessary steps and incorrect batch statuses.

## Rationale

To match each crop type’s actual process: seed-grown crops keep the full ladder, rooted cuttings start at growing, and bought-in finished plants start at ready, while discarded remains available at any step.

## Decided by

board

## Decided on

2026-04-28

## Impacts

Requires Aisha to redesign the status picker and Marc to add a crop type field and migrate existing batches; improves accuracy and reduces unnecessary steps for growers.
