# DEC-0002: Define batch status workflow

Back to the [decision log](../decision-log.md).

## Decision

Every batch of plants moves through one status ladder: propagating, growing, ready, sold. A batch can be marked discarded at any step.

## Context

Aisha showed two versions of the count screen. Both need a status for each batch of plants, and the prototype has no status field yet.

## Rationale

The group needed a consistent way to track plant batches through the greenhouse lifecycle.

## Alternatives considered

- Keep the prototype without a status field
- Add a status field but not define a workflow

## Decided by

Julie Tremblay, Marc Gagnon, Aisha Benali, Paul Nguyen

## Decided on

2026-03-03

## Impacts

Adds status field to count screen prototype and batch table, defines workflow for all batches
